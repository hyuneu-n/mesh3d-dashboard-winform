MeshPnP3D — 3D 메시 기반 항공영상 위치추정 대시보드
=====================================================

■ 실행

  "RUN MeshPnP3D.cmd" 를 두 번 누르세요.
  (설치 없음. 압축만 풀면 됩니다.)

  * 필요한 것: Windows 10/11 64비트 + .NET 10 데스크톱 런타임
    없으면 실행 시 안내 창이 뜨고 받는 곳으로 연결됩니다.
    https://dotnet.microsoft.com/download/dotnet/10.0  → ".NET Desktop Runtime x64"


■ 지정할 것은 딱 두 개입니다

  왼쪽 사이드바 [데이터] 칸에서

    1) 참조 폴더 (타일 영상)   ← 예: 3Ddata\260713170055_600_50_2_000
    2) 쿼리 폴더 (labels.json) ← 예: 비행데이터셋\260804084824(300)

  * 레퍼런스 rtra 파일은 ★들어 있지 않습니다★ (1.3 GB 라 뺐습니다).
    갖고 계신 .rtra 경로를 왼쪽 첫 칸에 넣어 주세요.
    app\data\ 폴더에 넣어두면 다음 실행부터 자동으로 잡힙니다.
  * 나머지(신경망 모델, 지도, 카메라 설정)는 전부 동봉되어 있어 손댈 필요 없습니다.
  * 칸에 폴더를 마우스로 끌어다 놓아도 됩니다.


■ 쓰는 순서

  ① 위 두 폴더를 지정
  ② [▶ 분석 실행] 을 누른다
        - 진행바가 돌고, 끝나면 사라집니다.
        - 결과 CSV 가 app\results\dashboard\ 아래에 자동 저장됩니다.
        - 543장 기준: sp-lightglue + GPU 로 약 30초, AKAZE 로 약 100초.
  ③ 오른쪽 지도에 결과가 뜬다
        휠            확대·축소
        드래그        이동
        마커 클릭     상세 창 (오차값 + 레퍼런스/쿼리/정합 오버랩)
        가운데클릭    전체보기
  ④ [통계보기] — 요약표 + 그래프 6종

  * 이미 돌려놓은 결과를 보려면 ② 대신 [결과 CSV 불러오기] 를 쓰면 즉시 뜹니다.


■ 화면 읽는 법

  파란 점        정답 위치 (labels.json)
  주황/빨강 네모  계산된 위치   (빨강 = 오차 5 m 초과)
  노란 선        둘을 잇는 선 — ★선 길이가 곧 오차★
  왼쪽 아래      축척 막대

  상세 창의 값
    수평 오차 (TE)      계산 위치와 정답 위치의 수평거리   ← 주지표
    고도 오차           계산 고도 − 정답 고도
    3D 오차 (ECEF)      위 둘을 합친 직선거리
    오차 동/북 성분     오차의 방향. 한쪽으로 쏠리면 계통오차, 흩어지면 매칭 잡음
    GT 재투영           정답 위치로 되쏘았을 때의 픽셀 오차
                        ★정합이 실제로 맞았는지★를 눈이 아니라 숫자로 보는 값


■ 배경 지도

  [지도 보기] - [배경 지도] 에서 두 가지를 고를 수 있습니다.

    참조 타일 모자이크   지정한 참조 폴더의 타일을 이어 붙여 만든 것.
                        ★매처가 실제로 본 그림★ 이라 해석이 정확합니다.
                        처음 한 번만 20~30초 걸리고 그 뒤로는 app\mapcache\ 에 저장돼 즉시 뜹니다.
    위성지도             미리 받아둔 위성영상 (Esri, Maxar, Earthstar Geographics).
                        인터넷 없이 동작합니다.

  * 잠실 지역 지도는 이미 구워서 동봉했습니다 (app\mapcache\).


■ 설정 바꾸기

  왼쪽 [모델·설정] 을 건드리면 상태 문구가 빨갛게 바뀝니다.
  ★[▶ 분석 실행] 을 다시 눌러야 결과에 반영됩니다★ (자동으로 다시 계산하지 않습니다).

    특징점 검출 + 매칭 모델   sp-lightglue(기본, 빠름) / akaze / sift / r2d2 / alike / ...
    위치계산 (PnP 솔버)       SQPnP(기본) / EPnP / IPPE / P3P / AP3P / Iterative
                              + Known-Rotation (센서 자세값을 그대로 쓰는 기준선)
    참조 3D화                 mesh(3D 메시) / flat(2D 평면 가정 — 대조군)
    매칭 단계 RANSAC 종류     없음(기본) / RANSAC / MAGSAC++
    임계값 3종                매칭 단계(px) · 6-DoF PnP(px) · Known-Rotation(m)
    GPU 사용                  NVIDIA GPU + CUDA 가 있으면 신경망 매처가 크게 빨라집니다.
                              없으면 체크를 끄세요(CPU 로 동작).


■ 폴더 구성

  RUN MeshPnP3D.cmd    실행 파일
  읽어주세요.txt          이 문서
  app\
    MeshPnP3D.exe         본체 (인자 없이 실행하면 대시보드)
    data\*.rtra           3D 메시 아카이브 (1.3 GB)
    models\*.onnx         신경망 매처 모델
    mapcache\             미리 구워둔 지도
    results\dashboard\    분석 결과가 여기에 쌓입니다
    runtimes\             OpenCV / ONNX 네이티브



■ 명령줄로도 씁니다

  app\MeshPnP3D.exe --help
  app\MeshPnP3D.exe --map <results.csv>        결과를 지도에 바로 올린 채로 시작
  app\MeshPnP3D.exe --build-map <참조폴더> <results.csv>   지도만 미리 구움


■ GPU 가 없어도 그대로 돌아갑니다

  NVIDIA 그래픽카드가 없으면 자동으로 CPU 로 넘어갑니다.
  ★결과(정확도)는 GPU 와 완전히 동일하고 속도만 느립니다.★
  GPU 를 못 쓰는 PC 에서는 [GPU 사용] 체크가 저절로 꺼지고 잠깁니다.

  543장 전수 기준 실측:

    매처              CPU      GPU     배수      CPU 메모리
    ------------------------------------------------------
    akaze             96초      -     (CPU 전용)    383 MB
    alike             99초     46초    2.2배        811 MB
    sift             219초      -     (CPU 전용)    513 MB
    sp-lightglue     308초     50초    6.2배      2,539 MB
    superpoint1024   323초    116초    2.8배      1,485 MB

  → CPU 만 있는 PC 라면 'alike' 를 권합니다.
    99초로 AKAZE 와 같은 속도인데 정확도는 오히려 낫습니다(1.678 m vs 1.908 m).


■ GPU 는 이미 켜져 있습니다 (설치할 것 없음)

  CUDA 12 / cuDNN 9 런타임을 함께 넣어 두었습니다.
  NVIDIA 홈페이지에서 따로 설치할 필요가 없습니다.

    · NVIDIA 그래픽카드가 있는 PC  → 자동으로 GPU 를 씁니다
    · 없는 PC                      → 자동으로 CPU 로 넘어갑니다 (결과 동일, 속도만 느림)

  두 경우 모두 아무것도 안 하셔도 됩니다.
